# Fettle

Fettle is a GitHub Action, CLI, and library for grading the maintenance health of repositories.

## Quick start

```bash
pnpm install
pnpm build
pnpm test
```

## Status

This repo is in its initial scaffold phase. The workspace is set up with a filtered TypeScript monorepo, reusable core contracts, and the CLI/action entrypoints needed to continue implementing the health rules and scoring behavior.
